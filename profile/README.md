# CRX•Money

Financial operations platform for small companies and private operators:
document intake, transaction review and matching, journal and reports,
with workspace-scoped data and auditable history.

This organization is the public home of the **CRX•Money Platform
integrations**: bank and exchange adapters organised by country, released
under the Apache-2.0 licence.

- Website: https://crx.money
- Integrations repository: `CRX-Money/platform-integrations` (in preparation)
- Contact: admin@crx.money
